Polankedex

el proyecto es una pokedex interactiva la cual permite fitrar por tipos,buscar por nombre del pokemon,poder agregar maximo 6 pokemon en un equipo el cual se guarda en el navegador.


Tecnologías utilizadas

HTML5
CSS3
JavaScript
PokéAPI
un titorial de youtube sobre el filtro por tipos
IA para acomodar el codigo

Cómo usarlo:

Clonar o descargar este repositorio.
Abrir el archivo `index.html` en un navegador web.
